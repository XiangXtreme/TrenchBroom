CSG 相减与挖空操作规范

使用 CSG 相减可以将一个或多个选中 Brush 的体积从目标 Brush 中扣除。使用快捷键 Ctrl + Shift + - 执行操作。

💡 技巧提示 (Tip)
在执行复杂形状的 CSG 挖空时，建议开启网格吸附（Grid 16 或 32），以避免产生微小的共面浮点误差裂缝。

trenchbroom.Document 事务与几何修改

所有对地图 Brush、Entity 的修改必须运行在 Document.transaction() 上下文管理器中，以确保原子性和撤销历史完整。

main.py (事务与选区平移) Python 3.11 
import trenchbroom as tb

doc = tb.documents.current()
with doc.transaction("Duplicate & Array"):
    for _ in range(5):
        doc.selection.duplicate()
        doc.selection.translate(64.0, 0.0, 0.0)
⚠️ 安全规则
严禁在事务外直接调用 selection.translate()，否则可能导致撤销树断裂。

第一步：创建封闭房间与贴图对齐

本教程将指导您从零搭建一个标准的封闭中空房间，并根据您所使用的游戏引擎选择不同的贴图与实体规范。

Quake 1 / 2 (标准轴对齐)
GoldSrc / Half-Life (Valve 220 投影)
Quake 3 Arena (曲面 Patches)

Quake 经典贴图锁定机制

使用标准 [x, y, z] 轴对齐投影，移动 Brush 时按住 L 可切换纹理锁定（Texture Lock）状态。

GoldSrc Valve 220 纹理系统

支持任意斜面 3D 旋转 UV，贴图比例和旋转角度将在几何变换时由 Valve 220 算法精确锁定。

Quake 3 贝塞尔曲面生成

支持按 Ctrl + Shift + C 将选中的长方体转换为光滑贝塞尔网格曲面。

💡 自动中空 (Hollow) 捷径
拉伸出一个长方体后，直接按下 #menu(Tools/CSG/Hollow) 并输入壁厚 16，即可一键生成无漏风的封闭空心房间！
