# 地图问题检查面板

更新：2026-11-09。状态：当前交互约定。

## 阅读与筛选

问题按现有校验规则分组，每组显示当前可见数量。超过八项的分类默认折叠。
搜索匹配中文分类、原始诊断、对象路径以及属性名和值；不会重新执行地图校验。
对象路径中的编号表示当前父节点内的位置，便于区分同名刷子，并不是持久对象 ID。
列表只显示对象名称、编号及相关属性；完整路径保留在悬停提示、详情及搜索中。
列表不显示源文件行号。详情先展示对象路径和属性值，再解释问题；原始诊断默认
折叠，按需展开。空属性值明确标注为空，修复、属性编辑和忽略操作按所选结果显示。
“问题类型”和“显示已忽略”与搜索共同生效。过滤后的分类操作只包含可见子项。

单击仅阅读详情，不改变地图选择。双击条目或“定位对象”才选择并聚焦地图对象，
单个面问题同时定位对应刷子面并打开面检查器。“编辑属性”跳转到场景页，
在当前表单或表格呈现中定位原生属性。隐藏、锁定或关闭分组中的对象需先变为可选。

非整数顶点可以来自有意的旋转、裁切或地形编辑；分类说明会解释吸附到 1 单位
网格的影响。面板不会自动吸附整张地图，也不会将所有检查项视为编译错误。

## 处理问题

分类与条目支持多选，重复选中的结果只处理一次。修复菜单仅显示所有所选问题
共有的原生修复操作，执行前确认动作与数量。一次批量修复对应一次原生撤销；
执行后重新检查并报告全图剩余检查项数。该数量包含其他类型及已忽略问题，
不能将它理解为此次修复的失败数。原生修复失败仍由输出日志报告。

“忽略”按对象和问题类型生效，不隐藏地图对象，不修改地图文件，关闭地图后
不保存。勾选“显示已忽略”后可恢复这些结果。忽略一条属性诊断也会忽略同一
对象上的同类属性诊断。

编辑时继续显示上次检查的文本，更新期间禁用定位和修复等操作。列表只保存文本
快照；失效的原生诊断不会被延迟操作解引用。刷新保留分类展开状态、滚动位置和
仍然有效的选择，重新生成的诊断需要重新选择。

## 验收

- `IssueBrowserView`：搜索、筛选交集、只读选择、定位及属性信号、忽略恢复、
  删除后读取、刷新稳定性、批量属性删除与撤销、中文翻译。
- `SelectionPropertyEditor`：两种呈现中的属性导航及原有编辑工作流。
- UI 快照 `issues` 与 `issues-empty`：实际工作台中的分组详情和空筛选状态，
  覆盖 Light、Dark、Blender 主题；较高缩放下仍可滚动阅读详情。

检查规则仍由原生 Validator 注册表提供；增加规则时，未知分类和修复名称会回退
到其原始描述。新增 Issue 子类需覆盖 `clone()` 保留自己的修复数据，批量修复
通过这些短期快照避免首个修改销毁后续诊断。
