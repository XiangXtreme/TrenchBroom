# GoldSrc 地形材质工具

本文定义 `.tbproj` 中的编辑、预览与编译流程。文末的 MAP/WAD 样例可以立即复现坡面裁剪后的结果，右侧面板和工程数据接入是后续实现。

## 编辑契约

| 数据 | 谁负责 | 保存什么 |
| --- | --- | --- |
| 源地形 | 作者用普通 Brush 工具制作和裁剪 | 地图中的 Brush 组和可涂刷面范围 |
| 材质笔迹 | 作者在 3D 视图刷草、泥、岩 | 区域局部坐标里的权重、默认材质及底材引用 |
| 生成方案 | TB 在应用时计算 | 经确认的源地形、权重、材质资源和生成器版本标识 |

创建区域时选一个普通 Brush 组，确认可刷顶面。首版支持在区域局部 XY 平面上，每个位置最多对应一个可刷表面的地形。坡折和外轮廓来自源 Brush。作者可以另外用普通贴图工具处理侧壁、台阶立面及悬挑。

刷材质只改权重。用裁剪工具时，选中和裁剪的是源 Brush。裁掉的笔迹由当前地形范围遮住，剩余区域保留原位置的权重。新裁出的侧面沿用普通贴图流程。撤销裁剪时，几何恢复后原笔迹重新显现。移动整组时，局部坐标随组移动。改高程时，重叠范围内的权重投到新顶面，新增区域使用默认底材。删组、切换所属组或让同一局部位置出现两个可刷面时，区域进入需检查状态，作者可以重新指定可刷范围。

## 右侧「地形」面板

面板与 Outliner、插件面板同级。选择已登记的地形组时显示区域参数，选择普通 Brush 组时提供「创建地形区域」。

| 区块 | 内容 |
| --- | --- |
| 区域 | 地形组、可刷面范围、默认底材、源地形和笔迹状态 |
| 涂刷 | 草、泥、岩材质槽，笔刷半径、强度和边缘软硬 |
| 切割预算 | 最大新增顶面数、最小面宽、WAD 预算、局部烘焙纹素密度 |
| 预览与应用 | 源顶面、预计新增顶面、预计纹理体积、异常位置和应用按钮 |

拖动时，视图显示笔刷权重的即时预览。松手后在后台重算受影响区域，并用叠加层区分保留原面、共享过渡带和局部烘焙。一次笔划对应一次撤销。源地形或笔迹修改后，状态变为「待重新应用」。应用失败时保留源地形、笔迹及上次应用记录，预览标出失败位置。

## 生成与保存

1. 从源 Brush 提取可刷平面和权重覆盖范围。每个源 Brush 独立裁切，所有子 Brush 必须是有效凸体，覆盖源 Brush 体积并共享边界。编译快照只输出其中一套地形实体。
2. 单一材质保留原面。连续而简单的两材质边界可提出切线。只有预计新增面数在预算内，最小面宽与 UV 质量满足约束，且能节省纹理时，才切出共享过渡带。共享边先统一顶点和 UV 相位，再生成 Brush。
3. 三材质交汇、急弯和未通过约束的候选用局部烘焙。先尝试较大的面和相同纹素密度。面与纹理预算无法同时满足时，预览列出超出的量，由作者修改笔迹或预算。
4. `.tbproj` 按地图资源和地形组的持久 ID 保存权重及配置。工作区保留源 Brush。已应用方案的几何和纹理可由输入和生成器版本重新计算。工程保存与撤销使用同一份区域状态，打开项目时校验应用记录的版本。
5. 在现有工程编译快照中，用已应用结果替换对应的源 Brush，把实际使用的贴图写入该快照的 WAD。地图导出也使用同一个生成入口。发现方案过期、地形无法分割或贴图缺失时，编译前给出对应区域和原因。

现有接入点包括 [Brush 裁切](../lib/TbMdlLib/include/mdl/Brush.h#L110)、[工程编译快照](../lib/TbUiLib/src/ProjectSession.cpp#L414)和 [WAD 写入](../lib/TbProjectLib/include/project/GoldSrcWad.h#L77)。

## 可复现的裁剪样例

在仓库根目录运行以下命令。样例把一段泥路刷过将要裁剪的位置，再用同一份权重和 WAD 生成斜坡与削平后的平台。

```powershell
$terrainExample = Join-Path $env:TEMP 'tb-terrain-clip-example'
node tools/map/terrain-material-demo/clip-example.cjs $terrainExample
Set-Location $terrainExample
hltools compile -threads 2 -noembedsource terrain_painted_before.map
hltools compile -threads 2 -noembedsource terrain_painted_after.map
```

| 在 TB 中依次打开 | 观察内容 | 地形顶面 |
| --- | --- | ---: |
| `terrain_source_before.map` | 整块原始斜坡 | 1 |
| `terrain_source_after.map` | 高处削成平台，坡折在 X=640、Z=40 | 2 |
| `terrain_painted_before.map` | 草、泥、岩笔迹与裁剪前的切面 | 283 |
| `terrain_painted_after.map` | 同一笔迹跨过坡折，生成面沿坡折分开 | 287 |

如果 TB 里还没显示纹理，把同目录的 `terrain_clip.wad` 加入地图的 WAD 列表。已用 `hltools` 编译四张地图。两张带笔迹的 BSP 分别是 303 和 311 个面，共用一份 0.293 MB 的 WAD。样例的裁剪线放在涂刷网格线上，生成切面与贴图仍使用 Web Demo 的算法。

原生版本验收时，在同一个 `.tbproj` 内完成「刷材质、裁剪、撤销、重做、保存重开、重编」。检查坡折两侧的贴图接缝、输出 Brush 的体积与边界、CS 1.6 内的行走碰撞，以及同一输入重复应用的面数和纹理一致性。
