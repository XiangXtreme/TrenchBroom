# 材质与 UV 编辑 {#materials_and_uv}

## 使用材质 {#working_with_materials}

在关卡编辑器中使用材质包含两个方面：[材质管理](#material_management)和材质应用。本节讨论后者，因此你将了解将材质应用到 Brush 面以及调整其对齐方式的不同方法。在深入介绍之前，我们先讨论三个一般性主题：材质浏览器、TrenchBroom 如何为新创建的 Brush 面分配材质，以及 TrenchBroom 中不同的材质投影模式。

### 材质浏览器 {#material_browser}

![材质浏览器](images/TextureBrowser.png) 材质浏览器是面检查器的一部分，用于两个目的：更改当前选中面使用的材质，以及选择 _当前材质_。每种材质的名称显示在其图像下方。当前正在使用的材质带有黄色边框，而当前材质带有红色边框。将鼠标悬停在缩略图上可查看材质名称和纹理尺寸。

缩略图上方有两行紧凑的控件。第一行是搜索字段。输入一个或多个以空格分隔的词，只显示名称中包含所有词项的材质。第二行包含以下控件：

- **名称 / 使用次数** 按字母顺序或当前使用次数对材质排序。
- **分组** 按[材质集合](#material_management)对材质分组。点击分组标题或其展开指示器，可折叠或展开该集合。
- **已使用** 将浏览器限制为当前地图正在使用的材质。
- **100%–500%** 更改缩略图缩放比例。你也可以按住 #key(Ctrl)，在浏览器上滚动鼠标滚轮，以步进浏览相同的缩放范围。

选定的缩略图缩放比例与 **Preferences > View > Material Browser > Icon size** 共用。普通滚轮操作仍会滚动浏览器。

要选中使用某种材质的所有面，请在材质浏览器中右键点击该材质，然后在弹出菜单中点击“Select Faces”。

要选中包含使用某种材质的面的所有 Brush，请在材质浏览器中右键点击该材质，然后在弹出菜单中点击“Select Brushes”。

### 筛选材质集合 {#filtering-material-collections}

![筛选材质集合](images/TextureCollectionEditor.png) 要筛选材质集合，请点击材质浏览器标题栏中的“Settings”按钮。这会显示一个用于启用或禁用各个材质集合的界面。在“Available”区域选择一个或多个材质集合，然后点击“+”图标启用它们。要禁用材质集合，请在“Enabled”区域选择它们，然后点击“-”图标。点击圆形箭头图标可重新加载所有材质集合。

点击材质浏览器标题栏中的“Browser”按钮，可返回材质浏览器。

### 材质投影模式 {#material_projection_modes}

在原版 Quake 引擎中，材质沿坐标系轴投影到 Brush 面上。实际上，引擎（准确地说是编译器）使用 Brush 面的法线来确定投影轴，所选轴是与面法线夹角最小的轴。然后，材质沿该轴投影到 Brush 面上。这会导致一定程度的失真（剪切），对于倾斜的 Brush 面尤其明显，因为此时面的法线同时线性依赖于坐标系的三个轴。不过，这种投影方式在 TrenchBroom 中称为 _旁轴投影_，也有一个优点：如果面的法线只线性依赖于两个或更少的坐标系轴（也就是说，它位于由其中两个轴定义的平面内，例如 XY 平面），旁轴投影就能确保材质仍然贴合 Brush 面，而无需更改缩放因子。

旁轴投影的主要缺点是无法实现完美的对齐锁定。_对齐锁定_意味着在面的所有变换过程中，材质都能完美保持在 Brush 面上的原位。例如，如果 Brush 沿 X 轴移动 16 个单位，那么 Brush 所有面上的材质相对于 Brush 都不会移动。使用旁轴投影时，面的法线会因变换而改变，材质可能因此失真，但无法补偿这种剪切。

这（可能）是 Half Life 引入 Valve 220 地图格式的原因之一。这种地图格式为 Brush 面扩展了每个面的 UV 轴附加信息。原则上，这使 UV 坐标可以因投影而进行任意线性变换，但实际上大多数编辑器都会让 UV 轴保持与面法线垂直。在这种情况下，材质沿面的法线（而不是坐标系轴）投影到面上。在 TrenchBroom 中，这种投影模式称为 _平行投影_，仅适用于采用 Valve 220 地图格式的地图。

### TrenchBroom 如何为新 Brush 分配材质 {#how-trenchbroom-assigns-materials-to-new-brushes}

在 TrenchBroom 中有“当前材质”的概念，我们已在前面的章节提到过。最初不会设置当前材质，它会通过两种操作改变：选择 Brush 面，或在材质浏览器中点击某种材质来选择当前材质。当 TrenchBroom 创建新 Brush 或新 Brush 面时，可能会查询当前材质，以确定应用于新创建 Brush 面的材质。但并不总是如此：有时 TrenchBroom 能根据操作上下文确定新创建 Brush 面的材质。我们之前在 [CSG 操作](#materials_and_csg_operations)中讨论过这种情况。在其他情况下，例如使用鼠标创建新 Brush 时，TrenchBroom 始终会应用当前材质。

### 手动分配材质 {#assigning-materials-manually}

要更改当前选中面的材质，请在材质浏览器中左键点击某种材质。如果你选中的是 Brush（且没有选中其他对象），此操作同样有效，此时新材质会应用到当前选中 Brush 的所有面。

你也可以将材质和属性从一个面传输到另一个面。这里的“属性”指几乎所有可以通过[面属性编辑器](#face_attribute_editor)修改的特征，例如偏移、缩放或表面标志 &mdash; 唯一的例外是内容标志；目标面上的内容标志始终会原样保留。

要执行传输，先使用 #key(Shift) + 左键点击选中源面。然后根据要传输的内容，按住以下修饰键组合之一：

修饰键                   含义
-------------            -------
#key(Alt)                从选中面传输材质和属性（将其投影到目标面上）
#key(Alt)#key(Shift)     从选中面传输材质和属性（将其旋转到目标面上，仅适用于 Valve 格式地图）
#key(Alt)#key(Ctrl)      仅传输材质（保留目标面的属性）

然后根据要传输到哪些面，执行以下操作之一：

操作                       要传输到的面
-------                    --------------------
鼠标左键点击               被点击的面
鼠标左键拖动               拖动经过的所有面（每个后续经过的面都会从上一个面传输）
鼠标左键双击               目标 Brush 的所有面

需要说明的是，使用 #key(Alt) 修饰键会将源面的 UV 轴复制到目标面，而不会对其进行调整。有时这是理想结果，但如果两个面的法线差异很大，可能导致目标面上的材质被拉伸。#key(Alt)#key(Shift) 组合通过将源面的 UV 轴旋转到目标面来避免这一问题，但仅适用于 Valve 格式地图。

最后，你可以使用复制和粘贴，将选中面的材质和属性复制到其他面上：

1. 选中要复制的源面，然后选择 #menu(Menu/Edit/Copy)
2. 选中要复制到的面，然后选择 #menu(Menu/Edit/Paste)

### 替换材质 {#replacing-materials}

如果要用另一种材质替换某种特定材质，可以选择 #menu(Menu/Edit/Replace Material...)。这会打开一个窗口，你可以在其中使用两个材质浏览器选择要替换的材质和替换材质。下方截图展示了这个窗口。

![材质替换窗口（Mac OS X）](images/ReplaceTexture.png)

在左侧材质浏览器中选择要替换的材质。该浏览器默认只显示地图当前正在使用的材质。截图中，材质“b_pv_v1a1”已被选作替换对象，因此带有红色边框。然后在右侧材质浏览器中选择替换材质（截图中为“b_sr_20c”）。最后点击“Replace”按钮。如果当前没有选中任何对象，替换会应用到地图中的所有 Brush 面；否则仅应用到选中的 Brush 面。如果替换成功，被替换的面随后会被选中；否则选择保持不变。

### 设置面属性 {#setting-face-attributes}

面属性控制材质如何映射到 Brush 面上。至少，每个面都有 offset、scale 和 angle 属性。offset 允许你移动面上的材质，scale 因子会拉伸材质，而更改 angle 可以旋转材质。此外，一些引擎还有更多属性。Quake 2 增加了表面标志和表面值，以及额外的内容标志。所有这些值都可以通过不同方式更改：使用面属性编辑器直接输入值，使用 3D 视口中的键盘快捷键，或使用 UV 编辑器。

#### 对齐、校正和适配纹理 {#align_justify_fit_textures}

要快速对齐、校正或适配纹理到 Brush 面，可以选中该面并使用 UV 编辑器下方的按钮。

操作         行为
---------    --------
对齐         旋转纹理，使其平行于面的边缘。
校正         更改 offset，使纹理沿选定方向对齐到面的包围盒。
适配         更改 scale，使纹理（或其倍数）适配到面上，同时保持校正状态。


![对齐、校正和适配按钮](images/AlignJustifyFit.png) 点击四个三角形按钮之一，可将纹理校正到面的包围盒。如果纹理在选定方向上的尺寸是面沿同一轴尺寸的倍数，可以多次按下校正按钮来逐步切换不同选项。这对于从纹理图集校正纹理很有帮助。点击时按住 #key(Shift)，可沿相反方向切换选项。

下面三个按钮用于对齐和适配纹理。点击最左侧按钮，将纹理对齐到面边缘。反复点击可循环切换面边缘。点击时按住 #key(Shift)，可沿相反方向循环。

剩余两个按钮用于水平和垂直适配纹理。如果纹理小于面，反复点击会循环切换整数适配因子，每次将重复次数增加一步；按住 #key(Shift) 可沿相反方向循环。如果纹理大于面，适配按钮会缩放纹理，使其完整显示在面上。若要只显示纹理的一部分（1/n），点击时按住 #key(Ctrl) 可循环切换整数细分，按住 #key(Ctrl) 和 #key(Shift) 可沿相反方向循环。这种模式适用于 trim sheet，因为多个子纹理会打包到一张图像中。

四个校正箭头中央的按钮会自动适配纹理，也就是对齐、校正并适配纹理。

#### 面属性编辑器 {#face_attribute_editor}

面属性编辑器位于面检查器中，正好在 UV 编辑器和材质浏览器之间。它包含多个控件，用于编辑一个或多个选中 Brush 面的面属性。

![面属性编辑器（Mac OS X）](images/FaceAttribsEditor.png)

上面的截图中可以看到两种控件。数值输入控件由文本字段和用于增大或减小字段值的小按钮组成。文本字段会显示相应面属性的值，例如截图中 X Scale 的值为“1”。如果选中了多个 Brush 面，且所有面对应属性的值相同，文本字段会显示该值；否则会显示占位词“multi”。在上面的截图中，选中 Brush 面的 X Offset 各不相同，因此文本字段显示“multi”。所有选中 Brush 面的其他值都相同，所以其他属性编辑器显示具体值，而不是占位符。在文本字段中输入数字即可将所有选中 Brush 面的属性值设置为该数字。因此，如果在上面的示例中将“32”输入 X Offset 编辑器，之后所有选中 Brush 面的 X Offset 都会是这个值。

不过，微调按钮的工作方式不同。点击向上或向下箭头按钮，可以按某个增量值增大或减小相应面属性的值；该增量取决于网格设置和当前按下的修饰键。下表说明了各种情况下所选用的增量值。

属性         默认值       按下 #key(Shift)       按下 #key(Ctrl)
---------    -------      -----------------    -----------------
Offset       网格大小     2 * 网格大小          1.0
Scale        0.1          0.25                 0.01
Angle        15°          90°                  1°

请注意，这些增量会应用到每个选中 Brush 面的相应属性。因此，如果你选中了两个 Brush 面，一个 X Offset 为 0，另一个 X Offset 为 8，当前网格大小为 16，那么点击 X Offset 属性编辑器旁的向上箭头按钮后，两个 X Offset 将分别变为 16 和 24。只有在文本字段中输入值，才会将两个 X Offset 设置为相同的值。

除了使用按钮更改值外，在文本字段获得焦点时，还可以使用滚轮或方向键。滚动和方向键按照上表所述的相同规则确定增量值。

对于表示标志值的属性（例如 Quake 2 的表面标志和内容标志），面属性编辑器提供了另一种控件。这种控件在文本字段中显示标志值的文本表示；点击文本字段旁标有“...”的按钮后，会显示一个下拉窗口，可在其中更改标志。下拉窗口为每个标志提供一个复选框，你可以分别勾选或取消勾选。

如果当前选中的面具有不同的内容标志集合，内容标志文本字段会显示“multi”。请注意，对于支持内容标志的游戏，为给定 Brush 的所有面使用相同的内容标志几乎总是更合适，这样可以避免游戏中的意外行为。因此，当只选中一个 Brush 时，如果内容标志文本字段显示“multi”，这可能表示存在应该修正的错误。

如果选中的面具有不同的表面标志集合，表面标志文本字段也会显示“multi”，但这不一定需要修正。Brush 的不同面使用不同的表面标志通常是有效的。

#### 材质对齐快捷键 {#material-alignment-keyboard-shortcuts}

以下快捷键在 3D 视口中生效，并影响所有选中的 Brush 或 Brush 面：

属性         按键                                    默认值       按下 #key(Shift)       按下 #key(Ctrl)
---------    ----                                    -------      -------------------  -----------------
Offset       #key(Left)#key(Right)#key(Up)#key(Down) 网格大小     2 * 网格大小          1.0
Angle        #key(PgUp)#key(PgDown)                  15°          90°                  1°

命令                                      按键
-------                                   ----
水平翻转                                  #action(Controls/Map view/Flip textures horizontally)
垂直翻转                                  #action(Controls/Map view/Flip textures vertically)
重置对齐                                  #action(Controls/Map view/Reset texture alignment)
重置对齐为世界对齐                        #action(Controls/Map view/Reset texture alignment to world aligned)

这些操作是相对于 3D 摄像机解释的（“Reset”除外）。这意味着按下 #key(Up) 会在视觉上大致沿该方向移动材质，但 X 或 Y 偏移究竟增大还是减小，取决于摄像机和面的朝向。角度的处理方式类似：按下 #key(PgUp) 会在视觉上逆时针旋转材质，按下 #key(PgDown) 则会顺时针旋转材质。

#### UV 编辑器 {#uv_editor}

UV 编辑器位于面检查器顶部。使用 UV 编辑器可以调整当前选中 Brush 面材质的 offset、scale 和 angle。请注意，只有选中一个 Brush 面时才能使用 UV 编辑器。如果选中了多个 Brush 面，UV 编辑器将为空。

![UV 编辑器](images/UVEditor.png)

当前面的材质显示在 UV 编辑器背景中。材质会平铺显示，平铺边缘以灰色显示。这些平铺边缘称为 _UV 网格_。当前选中 Brush 面的形状以白色显示。黄色实心圆标记材质原点，与原点相交的两条红线标记材质的原点轴，它们用于缩放。较大的黄色圆是用于旋转材质的手柄。UV 轴在 Brush 面中心以红色和绿色显示。

要更改材质相对于 Brush 面的 offset，只需用鼠标左键点击并将材质拖到任意位置。请注意，材质会吸附到 Brush 面的顶点，以便于对齐。

你可以点击并拖动灰色 UV 网格线来缩放材质，网格线同样会吸附到 Brush 面的顶点。缩放是相对于材质原点进行的，原点由黄色圆标记。要更改缩放原点，可以左键点击并拖动黄色圆，或者左键点击并拖动原点处相交的红线。这些线允许你分别设置原点的 X 和 Y 坐标。原点会吸附到面的顶点和中心。

要绕原点旋转材质，可以左键点击并拖动较大的黄色圆，或者按住 #key(Ctrl)，在 UV 编辑器中的任意位置左键点击并拖动。角度会吸附到 Brush 面的边缘，以便根据面的形状进行调整。

如果地图使用[平行投影](#material_projection_modes)，则可以剪切材质。按住 #key(Alt)，同时左键点击并拖动灰色 UV 网格线即可剪切。

UV 编辑器底部有以下控件：

![UV 编辑器工具栏](images/UVEditorToolbar.png)

- 重置对齐。所有属性都会重置；对于[平行投影](#material_projection_modes)格式的地图，材质从面平面进行投影。在标准格式地图中，其效果与“重置对齐为世界对齐”相同。
- 重置对齐为世界对齐。所有属性都会重置，材质从轴向平面进行投影。
- 水平翻转材质
- 垂直翻转材质
- 将材质逆时针旋转 90°
- 将材质顺时针旋转 90°
- 用于细分 UV 网格的网格控件。这对于将较大 trim sheet 的一部分对齐到面上很有用。
