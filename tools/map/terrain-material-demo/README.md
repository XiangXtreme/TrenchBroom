# GoldSrc 地形材质实验台

在本目录执行 `python -m http.server 8765 --bind 127.0.0.1`，再打开 <http://127.0.0.1:8765/>。HTTP 页面会在后台线程刷新笔迹预览。直接打开 `index.html` 时，预览在松开笔刷后更新。

## 草泥岩涂刷

选刷草、刷泥或刷岩，在任一面板拖动。两边读取同一份网格顶点权重。左侧对混合区分块烘焙，右侧合并纯材质区域的方格，并给混合区的三角面分配 UV。同一对材质共用一张 128 × 128 过渡贴图。U 来自统一的平面投影，V 来自顶点权重，因此同一对材质在共享边上使用相同的 UV。

三材质交汇和 UV 两轴几乎平行的面会使用 64 × 64 局部烘焙贴图，其中有效区 48 × 48。交汇面在面边界视图中用橙色标出。相邻的过渡面与纯材质或烘焙面之间，底纹细节的相位可能不同。涂刷分辨率取决于 24 纹素的顶点网格。

```powershell
hltools compile -threads 2 -noembedsource terrain_multi_baked.map
hltools compile -threads 2 -noembedsource terrain_multi_uv.map
```

| 默认样图 | 分块烘焙 | 自动 UV + 局部烘焙 |
| --- | ---: | ---: |
| WAD 纹理数 | 29 | 20 |
| WAD 体积 | 0.656 MB | 0.224 MB |
| 地形顶面 | 50 | 438 |
| 编译后的 BSP 面 | 75 | 410 |
| 编译后的 BSP 体积 | 0.669 MB | 0.304 MB |

## 分块复用

在任一面板刷草或泥。两边共用权重图，显示各自 WAD3 解码后的像素。移动指针可以同步放大同一位置。切换 MIP 0–3 可检查各级贴图，勾选面边界可标记重复引用的过渡块。

两版都复用纯草和纯泥底纹。基准版给每个过渡块分配一张纹理，共享版只合并含边缘在内的权重与底纹相位都一致的过渡块。每块有 96×96 有效纹素和四边各 16 纹素的边缘区。底纹每 128 纹素重复一次，纯色区和混合区都按同一地图坐标采样。两版共用同一 256 色调色板，四级 mip 都保留跨块采样边缘。自由笔迹如果改变了一个块的权重形状，那个块会独立烘焙。

分别下载同一面板的 MAP 和 WAD3，将两个文件放在同一目录。用 hltools 编译两版，命令在该目录运行。

```powershell
hltools compile -threads 2 -noembedsource terrain_unique.map
hltools compile -threads 2 -noembedsource terrain_shared.map
```

将生成的 BSP 放进 CS 1.6 的 `cstrike/maps`。打开对应地图后，从直线段走过分叉处，对照近处纹理和远处接缝。

| 默认样图 | 独有烘焙 | 共享过渡纹理 |
| --- | ---: | ---: |
| WAD 纹理数 | 31 | 29 |
| WAD 字节 | 700,736 | 655,528 |
| BSP 纹理数据字节 | 677,284 | 632,132 |
| BSP 光照数据字节 | 28,734 | 28,734 |
| BSP 总字节 | 714,484 | 669,332 |

## S 弯对比

两版使用同一条 S 弯和同一块 1280 × 640 地图单位的斜坡。左侧按方格独立烘焙，右侧沿草泥边界切分 Brush。相邻段共用横截面顶点，U 按中心线的累计距离衔接，V 将过渡贴图的两端对到纯草和纯泥。两侧过渡带反向使用同一张 128 × 128 贴图。Web 预览按导出的 UV 采样 WAD3，可关掉面边界查看纹理。

```powershell
hltools compile -threads 2 -noembedsource terrain_bend_baked.map
hltools compile -threads 2 -noembedsource terrain_bend_strip.map
```

| 固定 S 弯样图 | 分块烘焙 | 三材质过渡带 |
| --- | ---: | ---: |
| WAD 纹理数 | 40 | 3 |
| WAD 体积 | 0.904 MB | 0.068 MB |
| 地形顶面 | 50 | 100 |
| MAP Brush 面 | 330 | 630 |
| 编译后的 BSP 面 | 82 | 131 |
| 编译后的 BSP 体积 | 0.919 MB | 0.116 MB |

这里的地形是固定宽度的一条路，转弯处按段改变 UV 的方向和比例。Web 预览可检查对齐，游戏内的过滤和光照需用编译出的 BSP 检查。
