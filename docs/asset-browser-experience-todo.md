## 1. 产品目标与适用范围

以 `.tbproj` 为日常创作与工程分享载体：用户导入素材，TB 负责转换、按需捕获、
依赖管理和发布适配。Asset Browsers 的体验增强服务于这条完整流程。

全局资产库管理器与编辑器 Content Browser 是同一资源体系的两个入口：前者负责
素材准备与维护，后者负责在工程中查找、检查和使用资源。两者的预览、类型信息、
筛选与状态解释应当互相照应，共享实现；操作目标由所在上下文决定。

本清单承接 [资产库与编译链路总纲](asset-library-master-plan.md) 的产品决策，
面板所有权遵循 [工作空间与面板体系设计](workspace-ui-architecture.md)，
控件遵循 [UI 组件样式治理](ui-component-style-governance.md)。
工程存储与编译架构继续由对应总纲负责，本清单聚焦浏览与使用体验。

参考基线为本地 `C:\Users\Xiang\Documents\forge_re` 中的 `docs/assets.txt`、
前端 bundle 与资源浏览器文案：模型变体预览、声音试听、天空环视/十字展开、
按地图使用情况筛选等。实施具体能力时须核对 TB 当前解析器和渲染器的支持程度。

### 续批：真实模型核验（本机 Half-Life 资源）

用本机安装的 retail 模型（gordon、agrunt、barnacle 等）核验了解析器，修正了两处与
实际数据不符的假设：

1. **顶点是 float32 三元组**，不是 int16。项目自带的 GoldSrcMdlScaler 早已按 float
   处理，解析器现在与之一致。
2. **三角形是命令流**，不是定长数组：正数是三角带、负数是三角扇、0 结束，每个顶点
   占 4 个 int16（顶点索引、法线索引、s、t）。这是此前“统计正确但画面错乱”的根因；
   参考本机 xash3d-fwgs 的 mod_studio.c 与 mdldec 确认。
3. **绑定姿态来自序列第 0 帧**。按 Valve 官方 studio.h 的 mstudioseqdesc_t（176 字节，
   numframes 在 +56、numblends 在 +120、animindex 在 +124）解码动画通道后，gordon 第 0
   帧的包围盒与该序列自带的 bbmin/bbmax 完全吻合，渲染出正确的人形而不是尖刺团。
4. **无动画数据时退回骨骼静止值**。外置 _T.mdl 序列组与没有序列的模型仍需该路径，
   解析器按 animindex<=0 或 seqgroup!=0 判定不可解码。

新增按环境变量启用的验收：设置 TB_GOLDSRC_MODEL 指向任意 retail .mdl 时，TbMdlLibTest
校验头、骨骼、Body 变体与非空几何，TbUiLibTest 校验预览场景与渲染管线；未设置时自动
SKIP，仓库不包含任何游戏资源。实测 gordon.mdl（42 骨骼、2 贴图、2 个 Body 变体，
77 个序列）渲染出的第 0 帧与该序列的 bbmin/bbmax 一致，agrunt.mdl 同样通过。

验证方法：先用 Python 版解码器（build-release-codex/codex-logs/mdl_render.py）出图，
确认顶点、三角带/扇与姿态合成正确后，再把同一套逻辑移植到 C++，两边渲染结果一致。

### 续批：Skin 贴图与动画播放（2026-11-01）

| 归属 | 职责 |
| --- | --- |
| `mdl::GoldSrcStudioModel` | 解码内嵌贴图（索引像素 + 768 字节调色板）、int16 skin 引用、每个三角带顶点的 s/t；`buildGoldSrcStudioMesh(bytes, variants, sequence, frame)` 输出纹理坐标、逐三角形贴图索引与 RGBA 贴图 |
| `renderModelPreview` | 按三角形光栅化，重心坐标插值 UV，双线性采样贴图并乘面光照；无贴图时退回平涂 |
| `AssetInspector` | 序列下拉、帧滑块、播放/暂停；按 fps 定时步进，切换序列时重置帧范围，摘要显示“序列名 frame N” |

实现细节（用真实资源核对）：

- UV 是 **texel 空间**：`u = s / width`、`v = t / height`，**不能**再做 `1 - t/height`
  翻转——翻转后整张人脸是倒的（已用 gordon 的头部截图对比确认）。
- skin 引用是 **int16**，不是字节；按字节读会把头部错误地贴成护甲贴图。
- 贴图起点是 `mstudiotexture_t.index`（绝对文件偏移），像素后紧跟 768 字节调色板。

验证：合成夹具加入红/绿两色贴图与 UV，断言渲染结果同时出现两种颜色；真实
gordon.mdl 下摘要显示 `look_idle frame 0`、序列下拉 77 项、帧滑块最大值 30，
播放后帧号自动前进。

仍待完成：外置 `_T.mdl` 序列组（需要同时打开外部文件）与骨骼控制器。
