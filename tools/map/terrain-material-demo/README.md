# GoldSrc 地形材质实验台

用浏览器打开 `index.html`。也可以在本目录执行 `python -m http.server 8765 --bind 127.0.0.1`，再打开 <http://127.0.0.1:8765/>。

在任一面板刷草或泥。两边共用权重图，显示各自 WAD3 解码后的像素。移动指针可以同步放大同一位置。切换 MIP 0–3 可检查各级贴图，勾选分块边界可标记重复引用的过渡块。

两版都复用纯草和纯泥底纹。基准版给每个过渡块分配一张纹理，共享版只合并权重和采样边缘完全一致的过渡块。每块有 96×96 有效纹素和四边各 16 纹素的边缘区，底纹的平铺周期为 32 纹素。两版共用同一 256 色调色板，四级 mip 都保留跨块采样边缘。自由笔迹如果改变了一个块的权重形状，那个块会独立烘焙。

分别下载同一面板的 MAP 和 WAD3，将两个文件放在同一目录。用 hltools 编译两版，命令在该目录运行。

```powershell
hltools compile -threads 2 -noembedsource terrain_unique.map
hltools compile -threads 2 -noembedsource terrain_shared.map
```

将生成的 BSP 放进 CS 1.6 的 `cstrike/maps`。打开对应地图后，从直线段走过分叉处，对照近处纹理和远处接缝。

| 默认样图 | 独有烘焙 | 共享过渡纹理 |
| --- | ---: | ---: |
| WAD 纹理数 | 31 | 22 |
| WAD 字节 | 659,936 | 456,500 |
| BSP 纹理数据字节 | 656,884 | 453,700 |
| BSP 光照数据字节 | 28,734 | 28,734 |
| BSP 总字节 | 694,084 | 490,900 |
